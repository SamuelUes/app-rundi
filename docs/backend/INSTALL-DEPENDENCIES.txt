# Instalar Dependencias Faltantes

## Comando para ejecutar:

npm install @nestjs/mapped-types class-validator class-transformer

## Qué instalan:

- @nestjs/mapped-types: Para crear UpdateDto extendiendo CreateDto (PartialType, PickType, etc.)
- class-validator: Validación automática de DTOs con decorators (@IsEmail, @MinLength, etc.)
- class-transformer: Transformación de objetos planos a instancias de clase

## Después de instalar:

1. Todos los errores de compilación se resolverán
2. La validación de DTOs funcionará automáticamente
3. El backend rechazará datos inválidos con mensajes descriptivos

## Reiniciar backend:

npm run start:dev
