# Dependencias Faltantes del Frontend

## Comando para ejecutar:

npm install @react-native-async-storage/async-storage @types/node expo-constants expo-location react-native-maps @react-native-community/geolocation

## Qué instalan:

- @react-native-async-storage/async-storage: Almacenamiento local para tokens y datos
- @types/node: Tipos de Node.js para process.env
- expo-constants: Para acceder a variables de entorno en Expo
- expo-location: Para obtener la ubicación GPS del dispositivo
- react-native-maps: Componente de mapa (Google Maps/Apple Maps)
- @react-native-community/geolocation: Geolocalización (alternativa)

## Después de instalar:

1. El cliente de API funcionará correctamente
2. Se podrá guardar el token de autenticación
3. Las variables de .env estarán disponibles
4. La ubicación GPS funcionará
5. Los mapas se mostrarán correctamente

## Iniciar el Frontend:

npm start

## Nota sobre permisos:

En app.json, asegúrate de tener:

{
  "expo": {
    "plugins": [
      [
        "expo-location",
        {
          "locationAlwaysAndWhenInUsePermission": "Permitir a la app acceder a tu ubicación."
        }
      ]
    ],
    "ios": {
      "infoPlist": {
        "NSLocationWhenInUseUsageDescription": "La app necesita tu ubicación para mostrarte conductores cercanos."
      }
    },
    "android": {
      "permissions": [
        "ACCESS_FINE_LOCATION",
        "ACCESS_COARSE_LOCATION"
      ]
    }
  }
}
